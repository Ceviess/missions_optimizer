# ⚔️ Tacticus Operations Optimizer

**Tacticus Operations Optimizer** — это веб-приложение на базе Streamlit и линейного программирования (`PuLP`), созданное для автоматического расчета и поиска оптимального распределения персонажей по миссиям операций в мобильной игре *Warhammer 40,000: Tacticus*.

Приложение учитывает ограничения ростера игрока (ранги, фракции, особенности), требования миссий (слоты, Grand Alliance, специфические теги) и максимизирует ценность получаемых наград на основе пользовательских весов.

---

## 📱 Структура использования

Приложение разделено на 5 последовательных шагов (вкладок):

1. **1️⃣ Веса наград**  
   Задание коэффициентов ценности для различных типов ресурсов. Оптимизатор отдает приоритет миссиям и бонусам с наивысшим весом.
2. **2️⃣ API и Загрузка**  
   Ввод `X-API-KEY` и загрузка персонажей игрока напрямую из API игры.
3. **3️⃣ Настройка миссий**  
   Выбор общей продолжительности операции (4, 6, 8 или 10 часов), добавление миссий, выбор их редкости, слотов, Grand Alliance, 1 типа активного бонуса и необходимых тегов/фракций.
4. **4️⃣ Расчет и Результат**  
   Запуск математического алгоритма и получение итогового списка назначений персонажей на миссии.
5. **5️⃣ Персонажи**  
   Таблица с полной информацией о загруженном ростере игрока.

## 🚀 Быстрый старт

### Вариант 1: Запуск через Docker 🐳 (Рекомендуется)

1. **Сборка Docker-образа:**
```bash
docker build -t tacticus-optimizer .

```


2. **Запуск контейнера:**
```bash
docker run -d -p 8501:8501 --name tacticus-app tacticus-optimizer

```


3. Перейдите в браузере по адресу из консоли (по умолчанию `http://localhost:8501`).

---

### Вариант 2: Локальный запуск (Python)

1. **Клонирование репозитория:**
```bash
git clone https://github.com/Ceviess/missions_optimizer.git
cd missions_optimizer

```


2. **Установка зависимостей:**
Рекомендуется использовать виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# venv\Scripts\activate   # Для Windows

pip install -r requirements.txt

```


3. **Запуск приложения:**
```bash
streamlit run app.py

```


Приложение откроется по адресу `http://localhost:8501`.

---

## 🔑 Где взять API Key?

1. Перейти на https://api.tacticusgame.com и авторизоваться
2. Перейти в раздел Settings в правом верхнем углу
3. Создать новый api ключ в форме CREATE NEW API KEY
4. Скопировать и вставить ключ на вкладке **«2️⃣ API и Загрузка»** в приложении.
